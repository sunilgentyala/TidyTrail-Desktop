Pre-release

See what's eating your disk.

TidyTrail Desktop scans a folder or drive and draws it as a squarified treemap, same idea as TreeSize and WinDirStat, then lets you move the biggest offenders straight to the trash. Windows and Linux, one Rust core, no telemetry.

What it does

Pick a folder or a whole drive. TidyTrail Desktop scans it, sizes every file and folder, and shows the result two ways.

Treemap view

Rectangles sized by file/folder size, colored by category. The biggest thing on disk is the biggest thing on screen, so you find it by looking, not scrolling a sorted list.

List view

The same scan as a flat, size-sorted table with a share-of-total bar per row, for when a table beats rectangles.

Drill down

Double-click a folder tile or row to scan into it. A breadcrumb bar tracks where you are and jumps back in one click.

Delete safely

Selected files and folders move to the OS trash or recycle bin, never a hard delete, so a bad click is recoverable.

Colored by category

Every tile's color comes from its file type, so a cluster of the same color reads as "this is all your video files" at a glance.

Two platforms, one core

The scanning, treemap layout, and trash-backed deletion logic all live in one Rust library, unit tested on its own and shared by both builds.

Windows

Lists every mounted drive letter automatically. Junctions and mount points are treated as zero-size leaves instead of followed, so a self-referential junction (Windows ships several) can't send a scan into an infinite loop.

.msi / .exe installer, or a portable .zip, unzip and run, no install.

Linux

Lists /, your home directory, and anything mounted under /media or /mnt.

.deb to install, or a portable .AppImage, chmod +x and run.

None of the Windows builds are code-signed yet, so Microsoft Defender SmartScreen will warn you the first time you run one ("Windows protected your PC"). That's standard for any unsigned app, not a sign of a problem: click More info, then Run anyway.

Build it yourself

Prefer to build from source instead of using a prebuilt release? You'll need Rust and Node.

git clone https://github.com/sunilgentyala/TidyTrail-Desktop.git
cd TidyTrail-Desktop
cargo test --workspace
npx @tauri-apps/cli build
